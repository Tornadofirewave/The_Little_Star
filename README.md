Activity 1:
I fundamentally  changed the way the game feels. The initial milestone 2 had basic button functions to open a door and the plan was to make puzzles that would require you to utilize the star in interesting ways to interact with all the buttons to open the door.

That was boring.

So, instead I made a boost bubble that whenever interacted with by the star or the player, it launches you upwards. You need to interact with the green bubbles to open a door still, but the gameplay focuses more on high action and smooth movement. Also, the star gains directional input now.
